AI 선택

번역할 AI를 골라요. API 키는 이 브라우저에만 저장되고, 고른 AI 회사로만 전송돼요.

요금 (선택) — 쓰는 모델의 100만 토큰당 가격을 넣으면 사용량을 돈으로도 보여 줘요.

온라인 동기화 (이메일 로그인)

claude.ai 페이지에서는 쓸 수 없어요. GitHub 웹앱이나 PC 프로그램에서 로그인해 주세요.

같은 이메일로 로그인한 모든 기기에서 글 목록·폴더·번역·설정이 실시간으로 맞춰져요.

Firebase 연결 정보 (처음 한 번만)
  1. console.firebase.google.com → 프로젝트 추가 (무료, 애널리틱스는 꺼도 돼요)
  2. 프로젝트 개요의 </> 웹 아이콘 → 앱 등록 → 나오는 firebaseConfig를 위 칸에 붙여 넣기
  3. 왼쪽 Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호 사용 설정
  4. Authentication → 설정 → 승인된 도메인에 추가 (PC 프로그램은 localhost라 이미 들어 있어요)
  5. 왼쪽 Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3(서울) → 프로덕션 모드
  6. Firestore → 규칙 탭에 아래 내용을 붙여 넣고 게시:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == uid; } match /shares/{sid} { allow read: if true; allow create, update: if request.auth != null && request.resource.data.owner == request.auth.uid; allow delete: if request.auth != null && resource.data.owner == request.auth.uid; } } }
  7. 이 앱에서 이메일·비밀번호를 넣고 새로 가입 → 다른 기기에서는 같은 연결 정보를 붙여 넣고 로그인

로 로그인했어요.

연결이 안 될 때 어디가 문제인지 차례로 확인해요

    번역 방식

    이름·용어·설정 메모는 번역 화면의 📖 번역 노트에서 적어 두면 모든 번역에 참고해요.

    ✎ 제목
    →
    글자 크기
    줄 간격
    화면 폭

    단축키: Enter 표시된 문장 번역 · ↑↓ 문장 이동 · N 다음 미번역 문장 · R 다음 검토 항목

    지금은 프리셋을 쓰지 않아요. 저장된 이름·용어·설정 없이 번역하고, 새로 찾은 것도 저장하지 않아요. 위에서 프리셋을 고르거나 ‘+ 새 프리셋’을 만들면 적을 수 있어요.

    여기 적은 이름·용어·설정은 이 프리셋을 쓰는 모든 글에 적용돼요. 소설 한 편(여러 장)마다 프리셋을 하나씩 만들어 두면, 다음 장을 번역할 때도 같은 이름·용어로 이어서 번역해요. 이름·용어는 번역할 문장(과 앞 문맥)에 원어가 나올 때만 AI에게 전달되니 많이 쌓여도 괜찮아요. 한 줄에 하나씩 “원어 → 번역” 형식으로 적어 주세요.
    앞 장 줄거리 (같은 작품의 앞 장을 다 번역하면 자동으로 요약해 두고, 다음 장을 번역할 때 참고해요)
    이 글에만 쓰는 용어집이에요. 공통 노트와 함께 적용돼요.
    지금 글의 번역을 파일로 내려받아요.

    🔎 용어·누락 검사

    번역 노트의 이름·용어가 번역에 제대로 쓰였는지, 빠지거나 지나치게 길어진 문장이 없는지 AI 없이 바로 확인해요. 번역을 마치면 자동으로도 검사해요.

    📖 앞 장 줄거리

    이 장의 줄거리를 요약해 프리셋에 기억해 두면, 같은 작품의 다음 장을 번역할 때 참고해요. (데이터 자동 저장이 켜져 있으면 장을 다 번역했을 때 저절로 만들어요)
